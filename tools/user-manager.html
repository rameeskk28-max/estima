Greenland Pump Suite – User Manager

Runs entirely on this computer. Passwords are never sent anywhere; only salted hashes are produced.

1Session secret (AUTH_SECRET) – do this once

Copy into Netlify → Site configuration → Environment variables as AUTH_SECRET. Keep it private. Changing it signs everyone out.

2Existing users (optional)

To add or remove users later, paste the current APP_USERS value from Netlify here and click Load.

3Add a user

Usernames are not case-sensitive. Use at least 8 characters for passwords (longer is better).
